# Hazardous Goods Policy

**Document ID:** POL-HAZ-01 | **Version:** 1.4 | **Effective date:** 2026-01-15 | **Owner:** Compliance

## 1. What counts as hazardous
Items classified as hazardous materials (hazmat) under DOT rules. In the MS catalog this includes **solvent-based industrial degreasers**. Water-based degreasers are not hazmat.

## 2. Shipping rules
- Hazmat ships **ground only**. Air freight is never available.
- A **$75 hazmat handling fee** applies per shipment.
- Add **3 business days** to normal processing time.
- Only the carriers below can move hazmat.

| Carrier | Hazmat accepted |
|---|---|
| XPO Logistics | Yes |
| Old Dominion | Yes |
| FedEx Freight | No |
| UPS Supply Chain | No |
| Estes Express | No |

## 3. Returns
Hazardous goods are **not returnable**, opened or unopened.

## 4. Documentation
A Safety Data Sheet (SDS) is available on request and is included with every hazmat shipment.
